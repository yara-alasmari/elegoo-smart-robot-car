# 🤖 Elegoo Smart Robot Car Project

An interactive applied robotics project featuring custom programming, hardware assembly, and real-time speed control for live technical workshops and activities.
## 📌 Project Overview
Developing and setting up an interactive smart robot car powered by **Arduino**, handling hardware assembly, ultrasonic sensor configuration, and customized motion programming to engage visitors and demonstrate robotics concepts.

## ⚡ Key Feature: Custom Speed Control Programming
* Developed a custom programming logic (using Arduino IDE) allowing live users and event participants to dynamically select and test custom speed values (ranging from lower speeds to maximum performance, e.g., 100 to 250+).
* Programmed real-time motor response to adapt instantly to user-defined speed inputs during interactive activities.

## 🛠️ Hardware & Components
* **Microcontroller:** Arduino board.
* **Sensors & Modules:** Ultrasonic Sensor (for obstacle avoidance), Servo Motor, and Camera Module.
* **Chassis & Power:** 4-Wheel Drive smart car chassis with motor driver and rechargeable battery pack.

## 🎯 Applications
* Utilized in interactive technical workshops and innovation exhibitions to provide a hands-on experience for visitors to program and test robot speeds in real-time.
